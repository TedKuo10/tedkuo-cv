# Ted Kuo 履歷（純靜態版）

沒有後端、資料庫或 API key。中文在 `/`，英文在 `/en/`。

## 預覽
解壓縮後，直接用瀏覽器開啟 `index.html`（中文）或 `en/index.html`（英文）。

## 修改內容
1. 編輯 `src/data.js`（經歷、專案、生活體驗，中英文）或 `src/ui.js`（介面文字、專案標籤與成果數字）。
2. 執行 `node build.mjs`，會重新產生 `index.html`、`en/index.html`、`sitemap.xml`、`robots.txt`。
3. 提交並推送到 GitHub，Pages 會自動更新。

## 檔案
- `style.css`、`app.js`：樣式與互動（沒有 JavaScript 時內容仍全部可讀）
- `assets/portrait.jpg`：大頭照
- `CNAME`：GitHub Pages 自訂網域 `tedkuo-cv.echowave.pro`
